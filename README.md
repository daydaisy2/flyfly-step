# 리훨 임챌 👣

훨훨처럼 살고 싶은 부부의 **지역별 임장노트** PWA.
유튜브 브리핑 → 임장 루트·지도 → 입지 요약 → 단지별 카드(도장·자금 세팅) → 인터뷰·총평 순서로
기록하고, 링크로 공유하면 누구나 **읽기 전용**으로 볼 수 있습니다.

## 무엇이 들어 있나

| 화면 | 내용 |
| --- | --- |
| 📌 기본 개요 | 지역명·임장일·별점·한 줄 총평, 핵심 단지, 매매·전세, 갭, **목표 예산·평형**, 임장 루트 요약, 도장 현황 |
| 🎬 유튜브 브리핑 | 훨훨 임장챌린지 영상 링크를 상세 상단에서 바로 열기 + 핵심 포인트 정리 |
| 🗺️ 임장 루트 & 지도 | 루트 한 줄, 이동 순서, **네이버지도 열기** 버튼, **지도 사진 첨부**(탭하면 확대) |
| 🏙️ 입지·동네 요약 | 교통·학군·상권·재건축, 동네 인상 |
| 🏢 단지별 카드 | 스펙·시세, **👣 임장 도장**, 단지별 **네이버지도 / 네이버부동산** 버튼, **매물별 자금 세팅** |
| 💬 인터뷰 & 총평 | 소장님·실거주 인터뷰, 살 만한 이유/걸리는 점, 매수 순위, 다음 액션 |
| ✅ 체크리스트 | 임장 전·현장·임장 후 3단계 14항목 |

## 두 가지 모드

| 모드 | 설명 |
| --- | --- |
| 보기(공개) | 링크를 연 누구나 지역·단지·인터뷰 기록을 읽기만 합니다. 추가·수정·삭제 버튼이 없습니다. |
| 기록(편집) | 오른쪽 위 🔒 를 눌러 6자리 비밀번호를 넣으면 ✏️ 로 바뀌고, 지역·단지·매물·체크리스트를 직접 고칠 수 있습니다. |

- 잠금 해제 상태는 브라우저 `localStorage` 에 기억되어 다음 방문부터 바로 편집됩니다.
- ✏️ 를 다시 누르면 잠깁니다.
- 비밀번호는 앱 안에 평문으로 들어 있지 않고 SHA-256 해시로만 비교합니다. (클라이언트 잠금이라
  화면의 버튼을 숨기는 용도이며, 서버 권한을 나누는 장치는 아닙니다.)

## 지도 사진 첨부

- 편집 모드에서 **📷 지도 사진 첨부** 를 누르면 폰 갤러리에서 사진을 고릅니다.
- 브라우저 `canvas` 로 **가로 최대 1400px JPEG** 로 줄여(필요하면 한 단계 더) 올립니다.
- 이미지는 방 본문이 아니라 `rooms/imchall-public-v1-img/<지역ID>` 노드에 따로 저장합니다.
  (방 본문은 15초마다 통째로 받아오므로 이미지를 본문에 넣으면 데이터가 커집니다.)
- 지역에는 `route.mapImg` 에 **첨부 시각(ms)** 만 남겨, 다른 기기에서도 바뀐 것을 알아챕니다.

## 👣 임장 도장

- 편집 모드에서 단지 카드의 **👣 임장 도장** 을 누르면 오늘 날짜로 `임장 완료` 도장이 찍힙니다.
- 다시 누르면(도장 지우기) 지워집니다.
- 지역 헤더와 단지 카드 제목에 **👣 방문 2 / 5단지** 처럼 현황이 나옵니다.

## 🧮 매물별 자금 세팅 계산기

단지 안에 매물을 여러 개 추가하고, 매물마다 아래를 계산합니다. (금액 단위는 **만원**)

- **매물 정보**: 아파트명(평수), 동·층향, 입주가능, 세대수(연식), 시·구·동, 공시가격, 시세, 전고점,
  전세 호가, 매매 호가
- **자금 세팅 전략**: `생초 LTV 70%` · `LTV 40%` · `전세 끼고(갭)` · `직접입력`
  - 대출금 = 매매가 × LTV (프리셋) → **대출 한도(DSR)** 나 **갭(매매−전세)** 을 넘으면 그 선까지만
  - **자본(초기투자금) = 매매 − 전세 − 대출**
  - 예상 금리(기본 5.0%)·기간(기본 30년)으로 **월 원리금 / 월 이자**
- **부대비용**: 중개보수(요율 기본 0.55%, 금액 직접 수정 가능), 취득세(주택 수·금액 간이 계산, 직접 수정 가능)
- **예상 총투자금 = 자본 + 중개보수 + 취득세** (카드 맨 아래 강조)

## 데이터

- 저장 위치: Firebase Realtime Database `rooms/imchall-public-v1`
  (`https://bubulife-678ac-default-rtdb.firebaseio.com/rooms/imchall-public-v1.json`)
- 지도 이미지: `rooms/imchall-public-v1-img/<지역ID>`
- 앱을 열면 한 번 읽고, 이후 저장할 때마다 해당 지역 노드만 `PUT`/`DELETE` 합니다.
- 다른 기기에서 고친 내용은 REST 스트리밍(EventSource)으로 받아오고, 연결이 안 되면
  15초 주기로 다시 읽습니다.
- 마지막으로 받은 내용은 `localStorage` 에 남겨, 오프라인에서도 그 화면이 열립니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (화면 + 잠금 + 계산기 + Firebase 동기화). 외부 라이브러리 없음 |
| `manifest.webmanifest` | 홈 화면 설치 정보 |
| `sw.js` | 오프라인 캐시 (Firebase 통신은 캐시하지 않음) |
| `icon-*.png` | 아이콘 4종 (192/512, maskable) — 노란 바탕 + 흰 카드 + 👣 |
| `robots.txt` | 검색 노출 차단 |

## 배포

정적 호스팅(GitHub Pages 등)에 그대로 올리면 됩니다. HTTPS 에서 열어야 잠금 해제
(WebCrypto)와 서비스워커가 동작합니다.

검색에 노출하고 싶다면 `robots.txt` 의 `Disallow: /` 를 지우고,
`index.html` 의 `<meta name="robots">` 는 원래 들어 있지 않습니다.
